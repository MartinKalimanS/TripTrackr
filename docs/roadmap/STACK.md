# Stack: every tool, library and service

The complete inventory. **Status**: _In use_ = already in the repository (versions are read from the
`package.json` files and `infra/` on 2026-10-21; the lockfile is authoritative); _Planned_ = this
roadmap adds it, with the step that does; _Decision_ = an owner decision is open (listed in
`ROADMAP.md` section 7). Nothing here may be swapped for another tool without a written amendment
(`.specify/memory/constitution.md`, Governance). **No hyperscaler dependency**: every external service
has a non-hyperscaler default (constitution, Technology and Platform Constraints).

Rule for versions: Expo packages follow `node_modules/expo/bundledNativeModules.json` for SDK 57 and move
together with `npx expo install --fix`; Dependabot ignores them on purpose (`.github/dependabot.yml`). A new
dependency is added with `npm install <pkg>` at the **repository root** (never inside a workspace), prefers a
version published at least 7 days ago, is checked for install scripts, and the lockfile is committed.

## 10. Things deliberately NOT used

`react-native-web` / `react-dom` (no web target, D-14); Expo Go (native modules); any ad, analytics or
tracking SDK (no ATT prompt, Play Data safety says no ad id); Session Replay and the Feedback widget (D-18);
`@turf/great-circle` (defective at the date line and poles: use `features/globe/great-circle.ts`);
`expo-updates` / EAS Update (not installed; OTA is a decision, OD-4 in `ROADMAP.md`); a direct card processor
(no card data touches our systems, FR-081); any hyperscaler-managed database, queue or storage.
