# Store readiness checklist

Launch gate for the App Store and Google Play. Every row is a checkbox with an owner; nothing
ships while a row in a **blocking** section is open. Dates and platform rules were verified on
2026-09-23 against Apple's "Upcoming requirements" and the Play Console help centre — re-verify
before each submission, they move.

Owner placeholders: `[[PLACEHOLDER: owner]]`. Fill in a name, not a team.

Legend: **B** = blocking for submission · **R** = required before the social/sharing layer goes
live (which is itself gated on the offline-sync acceptance suite — constitution II).
