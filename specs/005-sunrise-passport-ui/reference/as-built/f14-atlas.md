# F14 Retire Atlas (T564): as built

Branch `feat/f14-atlas` (from `feat/ui-stack`, base `8c0f415`). Task T564, spec FR-083 and SC-001, `contracts/design-tokens.md`
(C5-1 enforcement), `test/theme/atlas-values.test.ts`, `test/no-neumorphism.test.ts`. The rule used throughout: delete only what a
search of `src`, `test`, `scripts`, `e2e`, the root configs, `global.css`, the theme CSS builder and the gallery proves nothing reads;
where a screen or an adapter still reads an alias it is kept and listed below. No live visual changed: no screen file was touched, and
the screen tests pass unchanged.

## How "unused" was proved

Two throw-away scans (not committed): (1) every `export` of `src/theme/*` and `src/constants/theme.ts` against every other file of
`src`, `test`, `scripts`, `e2e` and the root configs, comments stripped; (2) every module of `src` against the files that import it
(alias and relative paths), tests counted apart from code. A candidate was deleted only with zero code readers; a reader that is a test of
the candidate itself was deleted with it. Then the usual greps by hand for the names (`grep -rnE "<name>" src test scripts e2e`), and
the five parallel `f14-*` worktrees were searched for the same names (none used one).

## Bundle effect

Metro bundles the import graph, and the two deleted components had no importer, so they were never in a release bundle: the effect on
the bundle is nil. The tree shrinks by 513 lines and 18 files touched (source of the two components 3,180 and 2,905 bytes, their tests
6,990 and 5,116 bytes). The retired Icon tones, `listEntranceMs` and the type are a few bytes of JavaScript. Not measured with
`expo export` (not cheap on this host).

## Addendum 2026-10-23: the shape tables are gone

`AtlasSpacing` (`date-field`, `conflict-notice`, `form-sheet`) became `Space[2|3|4]` (8, 12, 16) and `cornerStyle` (`photo-tile`, `pictured-rows`, `stop-list`, `tappable`) became `cornerOf` (`pill` is `full`): every value and the continuous curve are the same, so no visual changed. `AtlasRadius`, `AtlasSpacing`, `AtlasRadiusName` and `cornerStyle` are deleted from `theme/shape.ts` and the barrel with their tests; the shape ratchet ceiling is 0. `ATLAS_RETIREMENT=1` now has one red test, the text roles. Also fixed: `document-upload.test.ts` pinned which of two same-millisecond documents uploads first, but the repository breaks the tie with a random id (it failed about 1 run in 4); it now pins the sequence (start, end, start, end) only.
